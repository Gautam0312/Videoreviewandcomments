About this tool

  • Workflow: Reviewer logs comments → Developer marks "Fixed by NIIT" → once ALL comments on a video are fixed, it's "Ready for Reviewer" → Reviewer approves each fix → once ALL approved, video is "Signed Off."
  • Live Sync: once imported in Chrome/Edge, the tool silently re-reads the file every 3 seconds and writes back every 5 seconds. Changes made by someone else on a different row merge in automatically. If the same comment row is edited by two people, whichever edit has the most recent timestamp automatically wins.
  • Change tracking: every edit is stamped with the name you entered at setup and the exact date/time of the change — visible under each comment in Review Validations, and saved into the spreadsheet as audit columns.
  • Developers cannot add new comments on any tab. Developers may only mark "Fixed by NIIT" and add Follow-up Notes to existing comments.
  • Comments are grouped by Application → Video, collapsed by default. Use Expand All / Collapse All to control visibility quickly.
  • Signed-off videos are hidden from the Reviewer/Developer dashboard views but remain visible in Overview and in Review Validations' Signed-Off table.
  • Voice comments (Reviewer only): click Start Recording, speak, click Stop Recording when done. Recording auto-stops after 2 minutes. Nothing is submitted until you click Add Comment.
  • Use Prev/Next under the video to step through comments — the full comment text (no character limit) is shown directly below the video.
  • Timestamps are shown and stored as mm:ss.s everywhere for video position.

⚠️ Notes on live sync

  • Browsers cannot read your computer's actual username for privacy reasons — that's why you're asked to type your name once at setup.
  • Live sync only works in Chrome or Edge, via "Import Spreadsheet."
  • If your browser asks you to re-confirm file access, a red banner will appear at the top with a "Click to Resume Live Sync" button — click it once and syncing continues automatically.
  • Conflict rule: same field, same row, edited by two people — the edit with the latest timestamp is kept automatically.
