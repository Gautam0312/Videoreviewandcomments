👋 Welcome

This tool helps Reviewers and NIIT Developers collaborate on training-video QA using a local Excel file as the shared data store — no backend server required.

  • 📂 Reviewers log timestamped comments (text or 🎤 voice) while watching a video, then mark issues "Approved" once fixes are verified.
  • 🛠️ Developers view comments read-only, mark items "Fixed by NIIT", and add follow-up notes.
  • 🔒 Video Locking: a video locks automatically for the Reviewer the moment they log their first comment on it — Developers cannot edit any row on that video until the Reviewer clicks "Review Complete – Stamp & Sync", which releases the lock. The same applies in reverse for Developers marking "Fixed by NIIT". Locks also auto-expire after ~90s of inactivity as a safety net for crashed/abandoned sessions.
  • 🕑 Activity Log: every action is timestamped and visible in Review Validations.
  • 🔄 Live Sync (Chrome/Edge only): re-reads the file every 2s and writes every 3s (plus immediately after any action you take), merging only the rows/locks that changed.
  • ⚠️ Live sync only works between sessions sharing the exact same local file handle.
  • 🔍 Reviewers can run an Auto-Scan that OCRs frame corners across the video looking for URLs.
  • Browsers cannot read your system username, so please enter your name at setup.
